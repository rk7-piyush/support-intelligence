# Support Intelligence and Smart Ticket Routing System

An ML-powered customer-support intent classification
and ticket-routing prototype.

## Planned features

- Smart ticket routing and manual-review queue
- Support issue analytics
- Model evaluation dashboard

## ML approach

- Dataset: BANKING77
- Baseline: TF-IDF + Logistic Regression
- Comparison: TF-IDF + Linear SVM
